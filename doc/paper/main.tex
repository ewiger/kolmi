\begin{abstract}
We propose a dual-layer framework for semantic compression in language models.
The universal layer identifies an entropy sweet spot where text is semantically coherent and meaningfully compressible—not tautological (low entropy) nor incoherent (high entropy).
The utility-indexed layer shows that compression is fundamentally a family of instruction-conditioned projectors, each inducing a utility-relative quotient and equivalence class over language space.
We define utility-aware distances using Normalized Compression Distance (NCD) and Normalized Information Distance (NID), formalize a partial order over compatible utilities via refinement, and propose empirical quality criteria separating compression distortion, context distortion, and interaction residuals.
The result is not a single semantic hierarchy but a typed partial order of semantic quotients indexed by preservation utility.
\end{abstract}

\section{Conclusion}
Semantic compression in language models has two fundamental layers: a universal entropy sweet spot indicating semantic coherence independent of task, and a utility-indexed layer where compression directions form a partially ordered family. This dual-layer view supersedes single-chain abstraction hierarchies and provides empirically testable quality criteria grounded in information theory and semantic distance. Future work includes learning utility spaces, adaptive utility selection, and alignment via entropy calibration.
