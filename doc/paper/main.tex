\begin{abstract}
We propose a dual-layer framework for semantic compression in language models.
The universal layer identifies an entropy sweet spot where text is semantically coherent and meaningfully compressible—not tautological (low entropy) nor incoherent (high entropy).
The utility-indexed layer shows that compression is fundamentally a family of instruction-conditioned projectors, each inducing a utility-relative quotient and equivalence class over language space.
We define utility-aware distances using Normalized Compression Distance (NCD) and Normalized Information Distance (NID), formalize a partial order over compatible utilities via refinement, and propose empirical quality criteria separating compression distortion, context distortion, and interaction residuals.
The result is not a single semantic hierarchy but a typed partial order of semantic quotients indexed by preservation utility.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Semantic compression in language is often reduced to token reduction. However, meaningful compression requires specifying what semantic information must be preserved. Without a preservation utility or instruction, compression is underdetermined: should we preserve legal obligations, causal structure, emotional tone, or mathematical validity?

This paper formalizes semantic compression as having two layers: (1) a universal layer where all text has an optimal entropy regime for semantic coherence, independent of task; and (2) a utility-indexed layer where compression directions are parameterized by preservation criteria, forming a partially ordered family rather than a single abstraction chain.

Our main contributions are:
\begin{enumerate}
    \item A hypothesis and formalization of the entropy sweet spot: where semantic coherence exists between tautology (over-compression) and incoherence (incompressibility).
    \item A formal framework for utility-conditioned semantic projectors with approximate idempotence and utility-relative equivalence.
    \item Integration of Kolmogorov complexity (NID) and practical compression distance (NCD) as universal and empirical measures of semantic alignment.
    \item Empirical quality criteria decomposing compression, context, and interaction effects on semantic outputs.
    \item Evidence that utilities form a typed partial order, not a linear chain, requiring separate experimental validation per utility pair.
\end{enumerate}

\section{Text Entropy and the Semantic Coherence Sweet Spot}
\label{sec:entropy-sweetspot}
Let $M$ be a language model and $x$ a text. Define entropy per token:
\begin{equation}
H_M(x) = -\frac{1}{|x|} \sum_{i=1}^{|x|} \log p_M(x_i | x_{<i}).
\end{equation}

We posit that semantic coherence is non-monotonic in entropy:
\begin{itemize}
    \item When $H_M(x)$ is very low: text is highly predictable, repetitive, and tautological. The model encounters no meaningful prediction challenges.
    \item When $H_M(x)$ is very high: text is unpredictable and likely incoherent or random. The model assigns low probability to any continuation.
    \item When $H_M(x)$ is in an intermediate range: text has meaningful semantic structure that the model can meaningfully compress—not trivial, but learnable.
\end{itemize}

We hypothesize that there exists a model-dependent sweet spot $[H^-_M, H^+_M]$ where text achieves high semantic coherence while remaining compressible. Outside this range, text exhibits either tautological over-compression (below $H^-_M$) or incoherent incompressibility (above $H^+_M$).

\section{Normalized Information and Compression Distance}
\label{sec:nid-ncd}
The ideal measure of semantic similarity uses Kolmogorov complexity $K(x)$, the length of the shortest program outputting $x$. Normalized Information Distance (NID) is:
\begin{equation}
\mathrm{NID}(x, y) = \frac{\max(K(x|y), K(y|x))}{\max(K(x), K(y))}.
\end{equation}

Since $K$ is uncomputable, we approximate using a concrete compressor $C$:
\begin{equation}
\mathrm{NCD}_C(x, y) = \frac{C(xy) - \min(C(x), C(y))}{\max(C(x), C(y))},
\end{equation}
where $xy$ is concatenation. For semantic compression, we can use an LLM as $C$: $C(x) = |f_M(x)|$ in tokens, or a specialized compressor like NNCP.

\section{Problem Setup: Language, Utilities, and Compressor Families}
\label{sec:setup}
Let $X$ be a space of language objects and $U$ an abstract (possibly infinite) index set of utilities or preservation criteria. Define a semantic compressor family:
\begin{equation}
C : X \times U \to X, \qquad C(x, u) = f_u(x),
\end{equation}
where $f_u(x)$ is a compressed version of $x$ that preserves information relevant to utility $u$.

Examples of utilities:
\begin{itemize}
    \item $u_{\text{summary}}$: preserve gist in minimal tokens.
    \item $u_{\text{legal}}$: preserve legal obligations and liability.
    \item $u_{\text{causal}}$: preserve causal mechanisms and dependencies.
    \item $u_{\text{code}}$: preserve executable semantics.
    \item $u_{\text{safety}}$: preserve safety-critical constraints.
    \item $u_{\text{emotional}}$: preserve emotional or narrative tone.
\end{itemize}

Utilities may be compatible (forming chains) or incomparable (requiring separate evaluation).

\section{Instruction-Conditioned Idempotent Projectors}
\label{sec:idempotence}
For each fixed utility $u$, we model semantic stabilization as approximate idempotence:
\begin{equation}
f_u(f_u(x)) \approx f_u(x).
\end{equation}
This turns $f_u$ into a semantic projector: repeated application maps inputs to stable semantic forms relative to utility $u$.

Define utility-relative equivalence by invariance:
\begin{equation}
x \sim_u y \iff f_u(x) = f_u(y),
\end{equation}
or approximately with tolerance $\epsilon_u$ under utility-aware distance $d_u$:
\begin{equation}
x \sim_{u, \epsilon_u} y \iff d_u(f_u(x), f_u(y)) \le \epsilon_u.
\end{equation}

Each utility induces a quotient space $X / {\sim_u}$, partitioning language by equivalence under that utility.

\section{Utility-Relative Quotients and Refinement Order}
\label{sec:quotients}
For two utilities $a, b \in U$, define a refinement (coarseness) relation:
\begin{equation}
f_a \preceq f_b \iff \left( x \sim_b y \Rightarrow x \sim_a y \right),
\end{equation}
meaning $f_a$ is coarser (identifies more elements) than $f_b$. Equivalently:
\begin{equation}
f_a \circ f_b \approx f_a.
\end{equation}

Not all utility pairs are comparable. For example, $f_{\text{legal}}$ and $f_{\text{emotional}}$ may not have a natural refinement order because they preserve distinct semantic invariants.

The global structure is thus a typed preorder over utilities, not a linear chain:
\begin{equation}
\{f_u : u \in U\} \text{ with partial order } \preceq.
\end{equation}

\section{Utility-Aware Distance}
\label{sec:utility-distance}
Define utility-specific distance using NCD or NID on compressed outputs:
\begin{equation}
d_u(x, y) := \mathrm{NCD}_C(f_u(x), f_u(y)) \quad \text{or} \quad d_u(x, y) := \mathrm{NID}(f_u(x), f_u(y)).
\end{equation}

The choice of utility determines what semantic similarity becomes visible. For example:
\begin{itemize}
    \item $d_{\text{summary}}(\text{``The dog chased the cat''}, \text{``A canine pursued a feline''})$ may be very small (paraphrases).
    \item $d_{\text{legal}}$ for the same pair may be larger if subtle legal distinctions differ.
    \item Different utilities thus create different metric landscapes on the same language space.
\end{itemize}

\section{Quality of Semantic Compression}
\label{sec:quality}
Let $f_M(x | C)$ be a model's output for input $x$ under context/instruction $C$. Consider a compression candidate $k$ and two contexts $C, C'$:
\begin{align}
y_1 &= f_M(x | C), \quad y_2 = f_M(k(x) | C), \\
y_3 &= f_M(x | C'), \quad y_4 = f_M(k(x) | C').
\end{align}

Define:
\begin{align}
\Delta_k(x, C) &= d_k(y_1, y_2) \quad \text{(compression distortion)}, \\
\Gamma(x, C, C') &= d_k(y_1, y_3) \quad \text{(context distortion)}, \\
J_k(x, C, C') &= d_k(y_1, y_4) \quad \text{(joint distortion)}, \\
R_k(x, C, C') &= J_k(x, C, C') - \Delta_k(x, C) - \Gamma(x, C, C') \quad \text{(residual)}.
\end{align}

The residual $R_k$ measures nonlinear interaction between compression and context change. Small positive residuals indicate stable composition; large residuals indicate brittleness.

Define a multi-objective quality score:
\begin{equation}
S(k) = \lambda_1 \mathbb{E}_x\left[\frac{|k(x)|}{|x|}\right] + \lambda_2 \mathbb{E}_{x,C}[\Delta_k(x, C)] + \lambda_3 \mathbb{E}_{x,C,C'}[\max(0, R_k(x, C, C'))].
\end{equation}

Lower $S(k)$ is better. This balances compression ratio, semantic fidelity, and stability.

\section{Experimental Program}
\label{sec:experiments}
We propose experiments addressing three questions:

\subsection{Q1: Universal Entropy Sweet Spot}
\begin{enumerate}
    \item Compute $H_M(x)$ for diverse texts across multiple models.
    \item Identify percentile ranges where semantic coherence is highest.
    \item Validate that utilities stabilize under idempotence in sweet-spot regime.
\end{enumerate}

\subsection{Q2: Utility Comparability and Quotient Structure}
\begin{enumerate}
    \item Define representative utilities: summarization, legal, causal, code, safety.
    \item Test $f_a \circ f_b \approx f_a$ for each utility pair on held-out data.
    \item Construct comparability matrix: which utilities form chains, which are incomparable.
\end{enumerate}

\subsection{Q3: Compression Quality and Residual Interaction}
\begin{enumerate}
    \item Implement candidate compressors per utility.
    \item Measure $\Delta_k, \Gamma, R_k$ across models and test sets.
    \item Produce Pareto fronts: compression ratio vs distortion vs residual.
    \item Test whether low token ratio predicts high semantic fidelity (hypothesis: no).
\end{enumerate}

We synthesize these themes around instruction-conditioned quotients and entropy-based coherence, shifting focus from single compressor axes to typed families of utilities with partial refinement order.

\section{Conclusion}
Semantic compression in language models has two fundamental layers: a universal entropy sweet spot indicating semantic coherence independent of task, and a utility-indexed layer where compression directions form a partially ordered family. This dual-layer view supersedes single-chain abstraction hierarchies and provides empirically testable quality criteria grounded in information theory and semantic distance. Future work includes learning utility spaces, adaptive utility selection, and alignment via entropy calibration.
